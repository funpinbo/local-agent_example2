# 설치와 기동

## vLLM 설치
새 버전으로 올릴 때는 테스트 서버에서 먼저 띄운다. 설정 파일을 그대로 옮기면 기본값이 바뀐 옵션 때문에 기동이 실패할 수 있다.

## 기동 실패 사례
2026-11-09 2호기에서 새 버전 기동이 실패했다. 원인은 max-model-len 32768이 GPU 메모리에 맞지 않은 것이었다. 16384로 낮춰 해결했다. KV 캐시가 차지하는 메모리는 컨텍스트 길이에 비례하므로, 길이를 절반으로 줄이면 KV 캐시 자리도 대략 절반이 된다.

## 확인 순서
1. /health 응답 확인
2. 짧은 질문으로 첫 토큰 시간(TTFT) 확인
3. 동시 요청 부하 테스트
